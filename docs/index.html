Shapash is a Python library dedicated to the interpretability of Data Science models. Its visualizations are designed to be understood by everyone, not only by experts. Data Scientists can share and document their results in an HTML report, and end users can see what drives each prediction.

Features

  • Global and local explainability plots with readable labels
  • A web app to navigate from global to local explainability and filter subsets
  • Summarized local explanations, exported to a pandas DataFrame
  • Quality metrics to evaluate how far you can trust an explanation
  • A standalone HTML report, as a basis for an audit document
  • Deployment through an API or in batch mode
  • Text classifiers: word-level explanations and what-if analysis
  • Regression and classification, with most scikit-learn, LightGBM, CatBoost and XGBoost models

easy to set up

Provide a SmartExplainer class to understand your model and summarize explanation with a simple syntax

high adaptability

Very few arguments are required to display results. But the more you work on cleaning and documenting the data, the clearer the results will be for the end user
